# 館内放送アシスト（PA Assist）

管理事務室の管理員・警備員が、消防計画 別添「緊急放送スクリプト集」（パターンA〜E）を、**日本語のみ／英語のみ／日本語→英語**から選んで、スマートフォンの読み上げ機能で流すためのWebアプリ（PWA）です。

- 音声ファイルは使いません。声は端末の読み上げ機能（iPhone：Siri音声／Android：Google音声）、チャイムと警報音はアプリ内で合成します。
- ホーム画面に追加すれば、**通信がなくても起動・再生できます**。
- 放送する言語は各画面の上部で選びます。選んだ言語は端末に記憶され、次回も同じ設定で開きます。
- 住宅部会役員の招集文は**日本語のみ**です（役員は全員日本人のため）。「日本語のみ」「日本語→英語」のときだけ流れ、「英語のみ」では流れません（招集のチェック欄も表示されません）。

## 画面

| 画面 | 内容 |
|---|---|
| ホーム | A〜Eのボタン、読み上げ準備の状況（日本語・英語の音声があるか、オフラインで起動できるか） |
| 共通 | 画面上部の「放送する言語」で 日本語のみ／英語のみ／日本語→英語 を選ぶ |
| A 第一報 | 階を選ぶ（B2・B1・1〜31）→ 放送。役員招集を続けて流すかを選べる |
| B 避難指示 | 火元階を選ぶと直上階は自動で決まる。待機指示を続けて流すかを選べる |
| C 誤報／D 地震／E 津波 | 内容を確認して放送。Dは「震度5強以上」の追加文を流すかを選べる |
| 放送中 | 読み上げ中の文を強調表示、大きな停止ボタン、画面が消えないよう制御 |
| 手動読み上げ | 音が出ないときに、放送設備のマイクで読み上げるための日本語文と英語のカタカナ読み（階数も自動で入る） |
| 臨時放送 | ひな形を選んで文を書き換え、読み上げる。選んだ言語の入力欄だけが表示される。［ ］が残っていると放送できない |
| 設定 | 音声の選択、読み上げの速さ、テスト（日本語・英語・チャイム・警報音） |

## ファイル構成

```
index.html                画面の土台
css/style.css             デザイン
js/speech.js              読み上げとチャイム・警報音
js/app.js                 画面と操作
data/announcements.json   ★放送文（ここを直せば文言が変わる）
sw.js                     オフライン対応（Service Worker）
manifest.webmanifest      ホーム画面用の名前・アイコン
icons/                    アイコン
robots.txt / noindex      検索エンジンに載りにくくする設定
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`pa-assist`）。
2. このフォルダの中身をすべてアップロードする（「Add file → Upload files」で、フォルダごとドラッグ＆ドロップ）。`.nojekyll` も含めてください。
3. リポジトリの **Settings → Pages** で「Source：Deploy from a branch」「Branch：main ／ (root)」を選んで保存する。
4. 1〜2分後に表示される `https://<ユーザー名>.github.io/pa-assist/` が公開URLです。管理員にはこのURLだけを伝えてください。

> **注意**：無料プランの GitHub Pages は公開リポジトリが前提で、URLを知っていれば誰でも開けます。電話番号・部屋番号・個人名は `announcements.json` に**入れない**でください（今の文言には入っていません）。

## 管理員の端末に入れる（1台につき1回）

**iPhone（Safari）**：URLを開く → 共有ボタン → 「ホーム画面に追加」
**Android（Chrome）**：URLを開く → 右上︙ → 「ホーム画面に追加」（または「アプリをインストール」）

入れたら、**ホーム画面のアイコンから起動して**「設定・テスト」を開き、次を確認します。

- [ ] 日本語テスト・英語テスト・チャイム・警報音がすべて聞こえる
- [ ] ホームの表示が「読み上げ準備OK　オフライン起動OK」になっている
- [ ] 機内モードにしてアプリを起動し、日本語・英語とも読み上げられる
- [ ] マナーモード（iPhoneの消音スイッチ）をONにしても聞こえる。聞こえない場合、放送時はOFFにする運用とする
- [ ] 放送設備（イヤホン端子からの外部入力、またはマイクに近づける）を通して、館内で聞き取れる

英語の音声が見つからないと表示された場合：
- iPhone：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語 → 「Samantha」などをダウンロード
- Android：設定 → システム → 言語 → 音声出力（テキスト読み上げ）→ Google音声サービスの「音声データをインストール」で英語（米国）を追加

## 放送文を直すとき

1. `data/announcements.json` の該当する `text`（読み上げる文）と `kana`（英語のカタカナ読み）を書き換える。
   - `{floor_ja}` などの記号は、選んだ階（12階／12th floor／トゥエルフス・フロア）に置き換わります。消さないでください。
   - 読み間違いは `speechFixes` に「表記：読み」を追加すると直せます（例：`"１１９番": "いちいちきゅう番"`）。
2. `data/announcements.json` の `version` を今日の日付に変える。
3. `sw.js` 1行目付近の `CACHE = 'pa-assist-v1.1.1'` の数字を上げる（例：`v1.1.2`）。これで各端末に「新しい版があります」と表示されます。
4. GitHub にアップロードする。

## 原稿から変えた箇所（読み上げのため）

| 箇所 | 原稿 | アプリ | 理由 |
|---|---|---|---|
| C 誤報 | 誤作動（またはボヤ等）と判明 | 誤作動と判明 | 括弧書きは読み上げられない。ボヤは実際の火災なので、臨時放送で対応する |
| B 避難指示 | 〇〇階（火元階）および〇〇階（直上階） | 12階、火元階、および13階、直上階 | 括弧を読み上げ向けに言い換えた |
| B（最上階） | ― | 31階を選ぶと直上階なしの文に切り替わる | 31階の上に階がないため |
| B・D・E 英語 | Do NOT | Do not | 大文字を1文字ずつ読む端末があるため |
| D 英語 | … wait for rescue — do not … | … wait for rescue. Do not … | 文の区切りをはっきりさせるため |
| A・D 役員招集 | 英語なし | 日本語のみ（「英語のみ」では流れない） | 役員は日本人のみ。Dの追加文は「トイレ・排水」と「役員招集」の2文に分けた |

## 技術メモ

- 長い文は1文ずつに分けて読み上げます（Chromeで約15秒ごとに止まる不具合、iPhoneで読み上げ終了の通知が届かない不具合への対策）。
- iPhoneは、タップ操作の中で最初の読み上げを始める必要があるため、ボタンを押した瞬間に無音で読み上げを1回実行しています。
- 再生中は Screen Wake Lock で画面スリープを防ぎます（対応していない端末では「画面を消さないでください」と表示）。
- 読み上げの速さ（設定）は端末に保存されます。
